## 🔧 安装说明

### macOS
1. 下载对应芯片版本的 DMG 文件
2. 双击打开 DMG
3. 将 AnPai.life 拖入 Applications 文件夹
4. 打开应用即可使用

> ✅ macOS 版本均已通过 Apple 公证，可直接安装运行。

### Windows
1. 下载 `.exe` 安装程序
2. 双击运行安装
3. 按提示完成安装

> ⚠️ Windows 版本未签名，首次运行时可能会看到 SmartScreen 警告，点击 "更多信息" → "仍要运行" 即可。
